What it does

One WhatsApp message can announce three different events tucked between flyer text, recurring schedules, Luma links, and 50 emojis. The extractor walks the day's messages, sends each one to Claude with a structured-output system prompt, and saves a normalized JSON array — title, time, venue, price (in VND thousands), recurrence, event type, and a confidence score so you can filter or review the long-tail cases.

I built it as the data layer for a Da Nang nomad-events surface I was prototyping. Once the messages are structured it becomes trivial to filter, sort by area, drop into a calendar UI, or feed into search.

  • Node.js (ESM)
  • Anthropic SDK · Claude Sonnet 4.5
  • Structured-output prompt
  • JSON-only pipeline
